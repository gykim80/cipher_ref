# 집필 구성표

| 장 | 독자가 새로 이해하는 것 | 손으로 바꾸는 파일 | 화면 체크포인트 |
|---|---|---|---|
| 1 | Scene, Mesh, Light, Camera, render loop | 없음 | 축 위에 첫 캐릭터가 보인다 |
| 2 | clone, install, dev server | package.json | sample 마을이 열린다 |
| 3 | core/module/content 의존 방향 | src 폴더 | 파일을 찾을 수 있다 |
| 4 | world data와 environment module | sample-content.ts | 물과 집 위치가 바뀐다 |
| 5 | character catalog와 population | sample-content.ts | NPC 수와 행동이 바뀐다 |
| 6 | beat, trigger, objective, dialogue | sample-content.ts | E 대화로 목표가 진행된다 |
| 7 | 이름·색·설정·배포 | 전체 content | 자기 게임 URL이 생긴다 |

각 장은 원리, 직접 수정, 확인, 흔한 오류 순서로 씁니다. 설명만 읽고 넘어가는 장은 두지 않습니다.
